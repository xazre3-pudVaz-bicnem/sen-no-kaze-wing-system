## 2026-10-20 追記：E2E の admin 11-12（シミュレーターの合計と見積の合計の 25,300 円のずれ）

ローカル検証モード（E2E）だけの問題で、本番（Supabase）には関係しません。PR #539。

- **起きていたこと**：admin 11-12 で、見積依頼の直前にシミュレーターで読んだ合計より、保存した構成から作った見積の合計が 25,300 円低くなって失敗する（main でも同じ手順で同じ差額）
- **原因**：公開カタログ（商品・価格）のキャッシュ（`unstable_cache`）は `.next` に残るが、ローカル DB は開発サーバーの起動ごとに初期化される（`WING_LOCAL_RESET=1`）。前の実行が admin 11-12 の「ユニットバス +20,000 円」の後に止まると（初回のコンパイルの時間切れなど）、次の実行ではシミュレーターが前の実行のカタログ（590,000 円）を表示し、保存・見積は初期化した DB（570,000 円）で計算し直す。20,000 円 × 経費 1.15 × 税 1.1 ＝ 25,300 円。初期化はプロセスごとに 1 回のため、開発サーバーが実行の途中で再起動したときも、途中で DB だけが初期化されて同じずれが起きうる
- **修正**

| 標準構成なのに外観・平面図が「最も近い画像」表示だった | 外壁ガルバリウムにプレビューキーを付けた一方、画像ルール側のキーを更新していなかった | 外観ルールのキーを `exterior_galva` 込みに修正（`lib/seed/catalog.ts`） |
| `/dealers` に h1 が無かった | `RuleHeading` が常に h2 | 見出しレベルを指定できるようにし、`/dealers` は h1 に |
| 平面図クリック領域のテスト ID が UUID だった | カテゴリー ID をそのまま出力 | カテゴリーコードに変更（その後クリック領域自体を撤去） |
| マイグレーション未適用の DB にアプリだけ配信すると全ページ 500 | `preview_hotspots` 不在をエラーとして扱っていた | `lib/data/schema-compat.ts` で旧スキーマを既定値に寄せる |
| 本体のみの構成で見積依頼すると内装が必須だと言われて弾かれた | 見積作成側の検証に注文範囲を渡していなかった | `createQuoteFromConfiguration` と SQL の `validate_configuration_items` に `finish_level` を渡す |
| 高断熱仕様が「スマートロック・鍵」に入っており、本体のみでは選べなかった | 台帳上の分類が実態と合っていなかった | 新設の「断熱仕様」カテゴリー（本体のみから選択可）へ移動 |
| 担当代理店が自分の見積を開けず 404 になった | SQL の RLS は許可していたが、ローカル実装の `getQuote` が顧客本人と管理者しか通していなかった | `LocalStore.getQuote` に担当代理店の判定を追加 |

## 全画面の一括点検（2026-08-23）

`e2e/audit.spec.ts` が公開 17 ページ・会員 4 ページ・管理 14 ページを PC(1440) と SP(390) で開き、
横スクロール／ビューポートはみ出し／h1 の有無／alt 欠落／画像の読み込み失敗／名前のない操作要素を機械的に洗う。
`e2e/audit2.spec.ts` はリンク切れ・詳細画面・noindex・入力エラー時の表示・ポップアップ・SP の代理店入力を見る。

### 見つけて直したもの

| 症状 | 原因 | 対応 |
|---|---|---|
| `/news` `/contact` `/sct` `/privacy` に h1 がない | `RuleHeading` の既定が h2 | 4 ページを `as="h1"` に |
| SP で代理店の別途工事入力画面が 384px 横スクロール | grid の子が既定 `min-width:auto` で、44rem の表に押し広げられていた | 子に `min-w-0`、トラックを `minmax(0,1fr)` に |
| SP で保存仕様の詳細が 272px 横スクロール | 同上（40rem の表） | 同上 |
| オプションカテゴリー画面の説明が旧 UI のまま | シミュレーター改修時の取り残し | 文言を更新 |

### 誤検知として除外したもの

横スクロール領域（管理メニュー・広い表・カルーセル）や `overflow:hidden` の内側にある要素は、
ビューポートより広くても設計どおりなので検出対象から外した（祖先の `overflow-x` を見て判定）。
最終的に**全ページで横スクロール 0px・指摘なし**。
