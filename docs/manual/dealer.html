Wing 代理店運用マニュアル

はじめに

はじめに /register から会員登録してください。そのあと本部が代理店の権限を付与すると、管理画面が使えるようになります。

  1. 会員登録するお名前・メールアドレス・パスワード・電話番号・住所を入力します。法人名も入れておくと、本部の画面で見分けやすくなります。
  2. 本部に連絡する登録したメールアドレスをお伝えください。本部が権限を付与します。
  3. もう一度ログインする/login からログインし直すと、管理画面 /admin に入れるようになります。
Note

権限が付くまでは通常のお客様と同じ画面です。ログインしても管理画面が出ない場合は、まだ権限が付与されていません。

できること・できないこと

代理店の権限では、現地に関わる部分だけを操作できます。本体やオプションの価格は本部・総代理店が管理します。

できること

  • 担当として割り当てられた見積を開く
  • 別途工事・運送費の金額を入力する
  • 自社のフリー商品を登録して見積に載せる
  • お客様への申し送りを書く
  • 確定見積（次の版）を発行する
  • 商品台帳を見て、標準の仕様と価格を確認する

できないこと

  • 本体価格・オプション価格の変更
  • 商品台帳への商品追加（フリー商品を除く）
  • 他社が登録したフリー商品の編集
  • 割り当てられていない見積の閲覧
  • お客様の一覧や他社の情報の閲覧
  • 発行済みの見積書の金額の書き換え

お仕事の流れ

お客様 サイトで仕様を選び、見積を依頼する
本部 担当代理店として貴社を割り当てる
貴社 お知らせが届く。現地・搬入路・地盤・法規を確認する
貴社 別途工事とフリー商品を入力し、確定見積を発行する
お客様 確定見積を見て、進めるか見送るかを回答する
貴社 回答のお知らせが届く。以降の商談へ

ログインしてすぐのダッシュボードに「未読のお知らせ」「入力待ちの見積」「自社のフリー商品」の件数が出ます。まずここを見れば、やることが分かります。

お知らせ

/admin/notifications　貴社に関係する出来事だけが届きます。

  • 見積が割り当てられたとき
  • 担当した見積をお客様が承諾・辞退したとき

未読には赤いラベルが付きます。「開く」で対象の見積へ移動できます。対応が済んだら「すべて既読にする」で整理してください。

本部がメール送信を設定している場合は、同じ内容がご登録のメールアドレスにも届きます。

担当の見積に金額を入れる

/admin/quotes　貴社に割り当てられた見積だけが並びます。

  1. 「別途工事を入力」を押して見積を開く 上部にお客様の仕様（本体・注文範囲・選ばれた設備）と、本部が出した概算金額が表示されます。設置予定地は右側の顧客情報で確認できます。
  2. 並んでいる別途工事に金額を入れる 9つの項目があらかじめ 0 円で並んでいます。現地を確認して、それぞれの単価と数量を入力してください。発生しない項目は 0 円のままで構いません。
  3. 足りない項目を追加する 「別途工事を追加」で行を足せます。項目名・摘要・単価・数量を入れてください（例：傾斜地の追加基礎工事、擁壁の補強）。
  4. フリー商品を載せる 「フリー商品を追加」で自由に入力するか、登録済みの商品名のボタンを押すと名前と価格が入った行が入ります。
  5. お客様への申し送りを書く 現地条件・工期・注意事項など。見積書の備考に載り、お客様のマイページと PDF に表示されます。
  6. 合計を確認して発行する 入力しながら下部に「確定見積の合計」が出ます。内容を確認して「第2版として発行する」を押すと、お客様に通知が届きます。
Caution

発行すると前の版は「改訂済み」になり、お客様は新しい版を見るようになります。金額を直したいときは、書き換えではなくもう一度発行してください（第3版が作られます）。

計算のしくみ

本体価格とオプション価格には諸費用 15% が乗っていますが、別途工事とフリー商品には乗りません。入力した金額に消費税 10% だけが加算されます。税抜請負額は千円未満を切り捨てて計算します。

別途工事の考え方

設置場所によって変わるため、本部の概算見積には金額が入っていません。現地を確認して貴社が確定させる部分です。

あらかじめ並んでいる 9 項目です。
項目主な内容
運送費工場から設置場所までの運搬。4tユニック車 1台が基本
設計監理及び確認申請費建築確認申請が必要な場合の設計・申請費用
梱包養生運搬時の養生
現場設置工事クレーン設置と展開作業
電気設備工事引込み・配線・照明器具の取り付け
給排水給湯設備工事上下水の引込みと接続
基礎工事設置後の基礎施工
廃材処分費発生材の処分
別途現場諸費用交通費・労災・安全管理費など

お客様が選んだ注文範囲によって、必要な工事が変わります。「本体のみ（DIY）」を選ばれている場合は、内装や設備の工事は含まれません。見積画面の上部で注文範囲を確認してください。

防火仕様について

防火地域・準防火地域では防火構造が必要になります。お客様が「防火仕様」を選んでいる場合、金額は「別途見積」扱いです。建築する場所の指定を確認のうえ、別途工事に必要額を計上してください。

フリー商品を登録する

/admin/free-products　貴社が扱う商品（ベッド・イス・テーブルなど）を登録して、見積に載せられます。

  1. 「フリー商品を追加」を押すカテゴリーは「フリー商品」に固定されています。
  2. 商品名・コード・価格を入れるコードは英小文字・数字・ハイフンで、他と重ならないものにしてください（例 yamada-bed-s）。価格は税別で入れます。
  3. 画像を登録する1200×900px 程度、白または無地背景で商品が1つだけ写っているものが見やすいです。
  4. 保存する一覧に並び、見積の入力画面からワンクリックで載せられるようになります。
  • 登録した商品は貴社だけが編集できます。他社の商品は表示も編集もされません。
  • 見積書では「別途工事」の下に「5 フリー商品」として別枠で表示されます。
  • 諸費用 15% はかかりません。入力した価格に消費税だけが乗ります。
  • 一時的に出したくないときは、削除せず非公開にしてください。

商品台帳を見る

/admin/ledger　本体・仕様・分類・カテゴリー・商品の一覧です。閲覧のみですが、お客様への説明に使えます。

  • 本体は Wing（片ウィング）・BOX・フラットの 3 種類です。
  • 仕様はホテル仕様・住宅仕様・事務所／店舗用の 3 つ。選ぶと標準構成と平面図が切り替わります。
  • 各カテゴリーに「本体のみから」「本体＋設備から」「フル装備のみ」の注文範囲が付いています。
  • 価格は税別・諸費用別の金額です。見積書では 15% が乗った金額になります。

価格や商品の内容に誤りを見つけた場合は、本部へご連絡ください。台帳の編集は総代理店以上の操作です。

発行したあと

  • お客様のマイページに第2版・確定見積として表示され、PDF もダウンロードできます。
  • お客様が「この見積で進める」または「今回は見送る」を選ぶと、貴社と本部にお知らせが届きます。
  • 回答があるまで、一覧の状態は「発行済み」のままです。
  • 仕様変更などで金額が変わった場合は、最新の版から改めて発行してください。
見積書に載る文言

「運搬、設置費など設置場所によって変動する費用は別途工事となっていて、現地の代理店、工務店にお問合せ下さい。」という注記が入り、その下に代理店紹介ページへの導線があります。お客様からのご連絡先として機能します。

困ったときは

管理画面に入れない

権限がまだ付与されていない可能性があります。会員登録が済んでいることを確認のうえ、登録メールアドレスを本部にお伝えください。付与後は一度ログインし直してください。

担当の見積が一覧に出てこない

本部の割り当てがまだです。お客様から直接ご相談を受けている場合も、システム上は本部が割り当てるまで開けません。本部にご連絡ください。

「この版はすでに改訂されています」と出た

古い版を開いています。一覧から最新の版を開いて入力してください。

入力した金額が合計に反映されない

単価か数量が空になっていないか確認してください。数量は 1 以上、単価は 0 以上の数字が必要です。項目名が空の行はエラーになります。

フリー商品のコードが登録できない

他の商品と同じコードは使えません。英小文字・数字・ハイフンだけで、貴社名を頭に付けるなど重複しない付け方をおすすめします。

本体価格を値引きしたい

本体・オプションの金額は変更できません。値引きが必要な場合は本部にご相談ください。別途工事側での調整はこの画面で行えます。
