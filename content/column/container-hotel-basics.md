## コンテナホテルとは何か

「コンテナで宿をつくる」と聞くと、金属製の海上コンテナを改装した施設をイメージする人も多いかもしれません。しかし当社の折り畳み式木造コンテナで宿泊施設をつくる場合は異なります。外観は一般的な木造建築と変わらず、内部も従来の宿泊施設と同じように設計できる、木造2×4工法による建物です。

工場で客室ユニットを製造し、現地で展開・組み立てる点が特徴です。つまり、「コンテナ」という言葉は流通・搬送の効率化を指しており、完成した建物は木造の宿泊施設そのものです。

## 木造2×4工法で実現する客室ユニット

コンテナホテルの客室は、工場で木造2×4工法の壁・床・天井が一体化したユニットとして製造されます。このユニット設計には以下の利点があります。

- **品質管理が厳密**：工場環境での製造により、寸法精度と施工品質が安定する
- **搬送効率が高い**：折り畳み式（Wing）、固定式（BOX）、水平折畳み式（Flat）から選択でき、敷地や搬入経路に合わせられる
- **小規模から段階的に拡張可能**：1ユニットから始められ、後に客室を追加できる

これらのユニットを現地で組み合わせ、共有部分（ロビー・浴室・食事施設など）を別途設計することで、小規模から中規模の宿泊施設が実現します。

## 客室設計の考え方

コンテナホテルの客室設計では、ユニット化と快適性のバランスが重要です。

工場製造のユニットであっても、内装・設備はプロジェクトごとにカスタマイズできます。ベッドのサイズ、収納、照明、壁紙の色や素材、床材など、宿泊施設のコンセプトに合わせて設計することが可能です。また、断熱材の仕様も選択できます。標準はグラスウール90mmですが、Wing では高断熱仕様としてスタイロフォーム90mmを選べるため、四季を通じて快適な客室環境を作ることができます。

外壁も、ガルバリウム鋼板または木板下見板張り（防腐剤塗り）から選択でき、周辺景観と調和した見た目にすることができます。

## 建物としての特徴

| 特徴 | 説明 |
|------|------|
| 構造体 | 木造2×4工法。工場での精密加工により安定性を確保 |
| 屋根 | ガルバリウム鋼板。耐候性が高く、メンテナンスが容易 |
| 外壁 | ガルバリウム鋼板または木板下見板張り。選択により印象を変更可能 |
| 地盤対応 | 伸縮式のジャッキベース付き柱脚により、不陸・傾斜地に対応 |
| 撤去・移設 | 折り畳み式・水平折畳み式の場合、将来的な移設が容易 |

この構造的柔軟性により、遊休地を活用した小規模宿泊施設から、観光地での季節営業施設まで、様々なビジネスモデルに対応できます。

## グランピング・体験型宿泊施設への応用

コンテナホテルはグランピング施設としても有効です。客室を自然環境に配置しながら、断熱・防水性能をしっかり確保できるため、快適さとロケーション価値の両立が可能です。

複数のユニットを離して配置することで、プライバシーを重視した設計も実現できます。段階的な施設拡張にも適しているため、事業の成長に合わせて客室数を増やしていくことができます。

## 導入前に確認すべきポイント

コンテナホテルの導入を検討する際は、以下を確認しておくと相談がスムーズです。

1. 敷地の搬入経路（道幅・カーブ・地盤支持力）
2. 敷地の不陸・傾斜状況
3. 想定する客室数と配置
4. 共有部分の設備内容（浴室・食事施設の有無など）
5. 将来の拡張や移設の可能性

建築確認や用途地域、旅館業・民泊の許認可については、自治体や保健所への確認が必要です。

## まとめ

コンテナホテルは、工場生産の効率性と木造建築の快適性を兼ね備えた選択肢です。客室の品質管理、段階的な拡張、敷地条件への柔軟な対応が可能な点が、従来の建築との大きな違いです。
