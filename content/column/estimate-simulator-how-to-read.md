## はじめに

折り畳み式木造コンテナWingの導入を検討するとき、サイトの見積シミュレーターを使って概算費用を確認する方が多くいます。しかし画面に表示される金額だけを見ていると、実際の総工事費用を大きく見誤る可能性があります。

このコラムでは、見積シミュレーターの結果がどのような項目で構成されているのか、何が含まれていて何が含まれていないのかを整理します。結果を正しく読み取ることで、代理店との相談をスムーズに進められます。

## 見積シミュレーターに含まれるもの

見積シミュレーターで表示される金額は、**工場で生産・製造する部分の概算**です。具体的には次の2つで構成されています。

**本体価格**

折り畳み式木造コンテナWingの基本的な構造体と、室内の標準仕様（床、壁、天井、基本的な照明など）が含まれます。

**オプション価格**

シミュレーターで選択した設備・機器の追加費用です。選べる主なオプションには以下のようなものがあります：

- ユニットバス（1216／3点ユニット）
- シャワーユニット
- トイレ（温水洗浄便座付き）
- 洗面器・混合水栓
- ミニキッチン
- ガス給湯器16号
- エアコン
- 折り畳み式ベッド
- スマートキー
- ウッドデッキ

これらをシミュレーターで選ぶと、それぞれの金額が加算されて表示されます。

## 見積シミュレーターに含まれないもの（別途工事）

重要なポイントは、シミュレーターの金額は**工場生産分だけ**という点です。実際に敷地に設置し、利用できる状態にするまでには、多くの別途工事が必要になります。これらは設置場所の詳細確認後に、代理店が別途見積ります。

**主な別途工事項目**

| 項目 | 内容 |
|------|------|
| 運送費 | 工場から現地までの輸送、4tトラック手配など |
| 基礎工事 | 地盤調査、杭打ち、コンクリート基礎、床高調整など |
| 現場設置工事 | ユニットの展開、据付、接合、シーリングなど |
| 電気設備工事 | 外部からの配線、分電盤、照明配線、コンセント設置 |
| 給排水給湯工事 | 水道・ガス・下水の接続、給湯器の取付 |
| 建築確認申請・設計監理費 | 自治体への申請書類作成、建築士による設計監理 |
| 廃材処分費 | 梱包資材などの処分 |
| その他 | 連絡通路、階段、手摺、外構工事など |

これらの金額はシミュレーターには含まれません。敷地の形状、地盤、搬入経路、電気・水道の配置、法令要件など、現地固有の条件によって大きく変わります。

## 見積シミュレーターの活用方法

見積シミュレーターは、**複数のプラン比較や概略予算把握**に向いています。以下の手順で活用することをお勧めします。

1. シミュレーターで希望する本体サイズと主なオプションを選択
2. 表示された工場生産分の金額を確認
3. 「この金額にプラス別途工事費がかかる」という認識を持つ
4. 敷地図面や現地写真を用意して、代理店に相談
5. 代理店が現地調査を実施し、別途工事の詳細見積を取得

シミュレーターの結果は、あくまで**検討材料の第一歩**と考えましょう。正確な総工事費用は、現地の詳細確認を経て初めて出揃います。

## 無料相談で全体像を把握

見積シミュレーターの結果を見て「この金額でいいのか、それとも別途工事を考えるともっと必要なのか」と迷ったら、早めに相談することをお勧めします。

当社の相談・初回見積もりは**無料**です。オンライン（Zoom等）での打ち合わせにも対応しています。シミュレーターの結果を見せながら、別途工事の内訳や、あなたの敷地に必要な工事について、具体的にご説明します。

## 相談前のチェックリスト

シミュレーターの結果を持って相談する際は、以下の情報があると話が進めやすくなります。

- 敷地の住所と簡単な配置図
- 敷地の形状と寸法（わかる範囲で）
- 搬入経路の道幅と曲がり角の状況
- 既存の建物や障害物の位置
- 電気・水道・ガスの引込状況
- 想定している用途（宿泊施設、事務所、店舗など）
- シミュレーターで選択した本体サイズとオプション

こうした情報を事前に整理しておくと、相談がスムーズに進みます。

## まとめ

見積シミュレーターで表示される金額は、工場生産分（本体とオプション）の概算です。実際の総工事費用には、運送費、基礎工事、電気・給排水工事、建築確認申請費など、多くの別途工事が加わります。

シミュレーターは検討の出発点として活用し、詳細な見積もりや全体像の把握は代理店の無料相談で進めることが、失敗のない導入につながります。
