折り畳み式木造コンテナの導入を決める前に、代理店に確認しておくべきことは何でしょうか。本記事では、見積・工程・保証範囲に絞って、発注前に必ず聞いておきたい質問をまとめました。

準備段階で土地や搬入経路を自分で確認することも重要ですが、ここで扱うのは見積書をもらった後、契約判断に必要な内容です。代理店との打ち合わせで使えるチェックリストとしてお役立てください。

## 見積の内容について確認する

サイトの見積シミュレーターで出た金額は、工場での本体製作とオプション部材の費用です。しかし実際の導入には、それ以外の工事が必ず伴います。

### 別途工事に含まれる項目を明確にする

まず確認すべきは、見積書に含まれている範囲です。以下の項目が別途工事として記載されているか、金額がいくらかを確認してください。

- **運送費** 工場から現地までのトラック手配
- **設計・申請費** 建築確認申請が必要な場合の費用
- **現場設置工事** 4tトラックからの搬入と展開
- **基礎工事** 地盤の準備、基礎コンクリート打設
- **電気設備工事** 分電盤、コンセント、照明配線
- **給排水給湯工事** 水道・ガス・排水の接続
- **廃材処分費** 梱包材や現場から出た廃棄物

シミュレーターで出た金額に、これらの工事費を足したものが総事業費になります。「見積に含まれているものは何か」を曖昧にしたままでは、後で思わぬ追加請求が発生する可能性があります。

### 変更・追加時の対応を聞く

打ち合わせの進む中で、仕様の変更や追加工事が生じることは珍しくありません。以下の点を確認しておきましょう。

1. 水回り設備（ユニットバス、トイレ、給湯）の選択肢の追加は、いつまで変更可能か
2. オプション追加時の納期への影響
3. 追加工事の見積を修正版として改めて提示するか、それとも着工後に発生した時点で請求するか

## 工程と納期について確認する

折り畳み式木造コンテナの導入は、相談から完成まで複数の段階を経ます。各段階の目安を理解しておくことで、予期しない遅延を防げます。

### 相談から工事開始までの期間

- **相談から仕様確定** およそ1〜2か月（設備選択、内装検討、間取り調整など）
- **工場での製作** およそ2〜3か月（本体と内装の生産）
- **建築確認申請が必要な場合** さらに別途期間が必要

これらの期間は目安です。土地の条件、現場工事の手配状況、季節によって変動します。自分が必要とする完成時期から逆算して、いつ相談を開始すべきかを判断してください。

### 現地設置から使用開始までの流れ

現地到着から実際に使える状態になるまでは、以下の流れになります。

1. 4tトラックでの搬入（道路幅や曲がり角の確認済みが前提）
2. 現地での展開・設置（約30分）
3. その後に基礎工事、電気・給排水工事を実施
4. 最終確認を経て使用開始

「設置当日に使える」と考えるのは誤解です。その後の工事期間がどのくらい必要か、工事中は自分がどこで過ごすのか、代理店と打ち合わせておくことが重要です。

## 保証と瑕疵担保について確認する

木造コンテナはプレハブ建築です。工場生産分と現場工事分で、保証の範囲が異なります。

### 本体に関する保証期間

構造体、屋根、外壁、設置直後の防水などの保証期間と、補修の対象範囲を確認してください。自然災害や施主の使用方法に起因する損傷が除外される場合、その内容を理解しておくことが大切です。

### 現場工事（基礎・電気・給排水）の保証範囲

代理店が手配する現場工事業者の保証は、通常、施工完了から1年です。ただし工事業者によって異なるため、明確にしておきましょう。

### 設置後の維持管理の責任

保証期間外の定期メンテナンスや点検について、代理店がどこまでサポートするのかを確認することで、将来の管理イメージが持ちやすくなります。

## 契約前確認チェックリスト

以下の項目について、代理店との打ち合わせで確認し、見積書や打ち合わせ記録に残しておきましょう。

| 確認項目 | 確認内容 | 確認済み |
|--------|--------|--------|
| 見積範囲 | 本体・オプション以外の別途工事が全て記載されているか | □ |
| 金額の根拠 | 変更や追加があった場合、いつまで対応し、どう金額が変わるか | □ |
| 工程表 | 相談から完成まで、各段階の目安期間が示されているか | □ |
| 納期 | 自分の必要時期に間に合うか | □ |
| 建確申請 | 建築確認申請の必要性と申請費用 | □ |
| 本体保証 | 構造、防水、設備の保証期間と除外事項 | □ |
| 工事保証 | 現場工事業者の保証期間と範囲 | □ |
| 打ち合わせ方法 | オンライン打ち合わせが可能か | □ |

## 相談時に活用できる支援

これらの確認は、初回相談の時点で全て完了する必要はありません。何度かのやり取りの中で整理していくものです。

当社では相談・初回見積もりが無料です。オンライン（Zoom等）での打ち合わせにも対応しているため、遠方からでも詳しく検討できます。不明な点は遠慮なく質問してください。

見積の概算を知りたい場合は、[見積シミュレーター](/simulator/wing-01)で必要な情報を入力することから始めることもできます。

## まとめ

契約前の確認は、その後の工事をスムーズに進め、後悔を防ぐための重要なステップです。見積の範囲、工程の目安、保証の内容に関する質問を用意して、代理店との打ち合わせに臨みましょう。

「本体に含まれるものと含まれないもの」についても別記事で詳しく説明しています。ご自分の用途に必要な設備や工事が何かを理解した上で、代理店に相談されることをお勧めします。

相談・見積もりは無料です。ご質問やご検討の内容について、いつでも[お問い合わせフォーム](/contact)からお気軽にご連絡ください。
