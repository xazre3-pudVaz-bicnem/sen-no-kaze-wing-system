## 本体だけで何がついてくるのか

折り畳み式木造コンテナWingを導入するとき、まず確認すべきは「本体のみ」の注文範囲です。本体には構造・外装・基本的な内装が含まれていますが、生活や事業に必要な水回り・電気・冷暖房などの設備は、ほぼ全てオプション選択になります。つまり、本体を購入しても「箱」の状態では使えません。用途に合わせて必要な設備を組み合わせることで初めて、実際に使える空間になります。

注文時に「本体のみ」「本体＋基本設備」「フル装備」など、複数の選択肢を用意する代理店が多いのはこのためです。見積の段階で、自分の用途に本当に何が必要なのかを考えることが、後悔のない導入につながります。

## 本体に含まれる構造・外装・内装

### 構造と外部仕上げ

Wingの本体には以下が含まれます。

- **木造2×4構造**：耐震性と耐久性を備えた枠組み
- **屋根**：ガルバリウム鋼板葺き
- **外壁**：角スパンガルバリウム鋼板、または木板下見板張り（防腐剤塗り）から選択
- **断熱**：標準のグラスウール90mm、または高断熱仕様のスタイロフォーム90mm
- **床・内壁**：基本的な仕上げ

### オプション設備の主な例

本体に含まれず、別途選択できるものは以下の通りです。

| 設備分類 | 具体例 |
|--------|--------|
| 水回り | ユニットバス（1216／3点ユニット）、シャワーユニット、洗面器・混合水栓、ミニキッチン |
| トイレ | トイレ（温水洗浄便座）|
| 給湯 | ガス給湯器16号 |
| 冷暖房 | エアコン |
| 照明・制御 | 照明、スマートキー |
| その他 | 折り畳み式ベッド、ウッドデッキ |

照明や一部家電については別途見積となる場合があります。

## 本体価格と工事費の関係

サイトの[見積シミュレーター](/simulator/wing-01)で表示される金額は、工場での生産分（本体＋オプション）の概算です。これには含まれないものが多くあります。

**見積シミュレーターに含まれるもの（工場生産分）**
- 本体構造と外装
- 選択したオプション設備

**別途工事となるもの（設置場所確認後に代理店が見積）**
- 運送費
- 基礎工事
- 現場設置工事
- 電気設備工事
- 給排水給湯設備工事
- 設計監理及び確認申請費
- 廃材処分費

これらの金額は、土地の条件・搬入経路・地域によって大きく異なるため、現地確認が必須です。見積シミュレーターの金額だけで判断すると、実際の総事業費とのギャップが生まれやすいので注意が必要です。

## 用途に合わせた設備選択の考え方

住宅・ゲストハウス・事務所・店舗など、用途によって必要な設備は大きく変わります。「本体のみ」で購入して後から設備を追加することも可能な場合もありますが、設計段階での配管・配線計画に影響するため、導入前に想定用途を固めておくことが重要です。

[製品ラインアップ](/products)では、Wingの仕様と標準的な選択肢を確認できます。代理店への相談時には、この情報を参考に「どのような使い方をしたいのか」を具体的に伝えることで、必要な設備を正確に提案してもらえます。

## 本体注文前のチェックリスト

本体と設備の範囲を整理するために、以下を確認しましょう。

- [ ] 用途（住宅・ゲストハウス・事務所・店舗など）は決めたか
- [ ] 宿泊機能は必要か（必要ならベッド・トイレ・シャワーが最低限必要）
- [ ] 食事調理の有無（ミニキッチンか、簡易的な設備か）
- [ ] 給湯の必要性（ガス給湯器、または電気温水器）
- [ ] 冷暖房の必要性と電源容量
- [ ] 電気容量の確認（オプション設備を合わせて必要容量を算出）
- [ ] 設置後の運用・管理体制（不在時や季節対応）

## まとめ

折り畳み式木造コンテナWingの「本体」は、構造・外装・基本断熱までが範囲です。生活に必要な水回り・電気・冷暖房などの設備は、ほぼすべてオプション選択になります。導入を検討する際は、用途と必要な機能を先に整理し、それに合わせて設備を選ぶことが重要です。

詳しい仕様や、より具体的な設備の組み合わせについては、[製品情報](/products)をご確認の上、代理店にご相談ください。自分の用途に必要な設備を正確に把握することで、実際の総事業費を見通しやすくなります。
