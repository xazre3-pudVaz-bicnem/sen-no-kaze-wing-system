折り畳み式木造コンテナWingの導入を考えて問い合わせるとき、何も準備せずに連絡しても構いませんが、あらかじめいくつかの情報を整理しておくと、打ち合わせがずっと効率的になります。相談から仕様確定までおよそ1〜2か月、製作におよそ2〜3か月のプロセスの中で、初回の打ち合わせ時間を無駄なく使うために、事前に用意しておくと良い情報をまとめました。

無料で相談できますので、わからないことがあればそのまま質問いただいても問題ありませんが、この記事を参考に最低限の情報を整理してから連絡いただくと、より具体的なご提案ができるようになります。

## 土地・敷地に関する情報

コンテナを設置する場所について、以下を事前に確認しておくことが大切です。

- **敷地面積と形状**：矩形か、斜面か、複数棟配置の場合は各棟の間隔
- **周辺の高さ制限**：近隣建物、電線、樹木などの位置と高さ
- **地盤の状況**：湿地帯か、山地か、砂地か、過去の浸水経験の有無
- **アクセス**：最寄りの道路からの距離と搬入経路の幅員
- **向き**：南北東西のいずれに開口させたいか、日当たりの希望

これらの詳細は、相談時に代理店が実地調査を行いますので、この段階では「大まかな土地の特徴を把握している」程度で構いません。ただし、既に [搬入経路のチェック](/setchi/delivery-route-check) を自分で確認済みでしたら、その結果を伝えていただくと、より正確な見積もりにつながります。

## 用途・施設種別

コンテナを何に使うかが、設備や仕様に大きく影響します。以下のいずれかに当てはまるか、あるいは複合的な使い方を想定しているか、整理しておきましょう。

- 宿泊施設（ゲストハウス、グランピング、農泊など）
- 事務所、店舗、カフェ
- 工房、スタジオ、ワークスペース
- 別荘、セカンドハウス
- 倉庫、物置
- その他（具体的な用途があれば）

特に **水回りが必要かどうか** は、設備の範囲と工事内容を大きく左右します。トイレやシャワー、キッチンを備えたいのか、それとも不要なのかを明確にしておくことが重要です。

## 実現時期と予算感

相談から施工完了までのスケジュール感を、あらかじめ想定しておいてください。

### 期間の目安

| プロセス | 目安期間 |
|---------|--------|
| 相談から仕様確定 | 1〜2か月 |
| 工場製作 | 2〜3か月 |
| 現地設置・展開 | 約30分 |
| 基礎工事・設備工事 | 別途工程 |
| 建築確認申請が必要な場合 | 別途期間 |

「○年の春に営業開始したい」「来年中に完成させたい」といった目標があれば、最初の相談時に伝えていただくと、スケジュールに余裕を持たせた計画が立てやすくなります。

また、サイトの [見積シミュレーター](/simulator/wing-01) で出た金額は、工場生産分（本体・オプション）の概算です。実際の見積もりには運送費、設計監理及び確認申請費、現場設置工事、電気設備工事、給排水給湯設備工事、基礎工事、廃材処分費などが別途加算されます。設置場所の確認後に、代理店が全体の見積もりを提示しますので、初回の打ち合わせで「おおよその予算感」を伝えていただけると、提案の方向性が定まりやすくなります。

## 初回相談前のチェックリスト

以下の項目を確認・整理してから、相談いただくと話がスムーズです。わからない項目は、相談時にご質問いただいても大丈夫です。

- [ ] 敷地の大まかな広さ（坪数や平米数が分かれば理想的）
- [ ] 設置場所への搬入経路の幅員（トラック4tサイズが通るか）
- [ ] 用途は何か（宿泊、事務所、その他）
- [ ] 水回り（トイレ、シャワー、キッチン）の必要性
- [ ] 複数棟の検討か、単棟か
- [ ] 実現希望時期（〇年〇月までに完成したい、など）
- [ ] 予算感（工場生産分のみか、全体工事を含むか）
- [ ] 将来、移設や用途変更の可能性

## まとめ

折り畳み式木造コンテナWingの導入相談では、土地の基本情報、用途、時期、予算感があらかじめ整理されていると、より正確で実用的なご提案ができます。この記事のチェックリストを参考に、事前に準備を進めていただければと思います。
