# 不足している画像一覧（required-preview-assets）

## 1. 設備・商品画像（見積項目クリック → 商品選択ポップアップ／見積書に表示）

先方より「メーカー問屋で作成中」とのこと。届き次第、**管理画面 › オプション › 画像** から登録してください。
推奨：**1200×900px（4:3）・JPEG/WebP・白または無地背景**。商品が 1 つだけ写っているもの。

| オプション（コード） | 必要な画像 |
|---|---|
| ユニットバス 1216（`ub-1216`） | UB 全景 |
| 3点ユニットバス 1216（`ub-3point-1216`） | 浴槽・トイレ・洗面が写る全景 |
| シャワーユニット 1116（`shower-unit-1116`） | シャワーブース全景 |
| シャワートイレユニット 1116（`shower-toilet-unit-1116`） | 全景 |
| トイレ（`toilet-washlet`） | 便器＋温水洗浄便座 |
| 洗面器 KB-PR012-03-G141（`washbasin-kb`） | 洗面器 |
| 混合水栓 KB-TP006-01-G141（`faucet-kb`） | 水栓 |
| ミニキッチン（`mini-kitchen`） | キッチン正面 |
| ガス給湯器 16号（`gas-boiler-16`） | 給湯器 |
| エアコン（`aircon`） | 室内機 |
| スマートキー（`smart-key`） | 本体 |
| 家具下足箱／ハンガーパイプ／洋服掛け／折り畳み式ベッド | 各 1 枚 |
| 内装セット（標準／ホテル仕様）（`interior-*`） | 床・壁・天井の仕上がりが分かる室内写真 |
| ウッドデッキ／サンルーフ／テーブル／冷蔵庫／洗濯機 | 各 1 枚 |

※ 提案書（UWⅡ）・PB（シエラ26）・建具標準品（ドレタス）のメーカー画像は転載禁止の注記があるため、そのまま使用していません。メーカーの許諾があれば同じ手順で登録できます。

## 2. 完成イメージ（選択状態に応じて切り替わる画像）

現状の登録（Wing のみ。`lib/seed/catalog.ts` → `seedPreviewRules`）：

| ビュー | 登録済みの条件 | 使用素材 |
|---|---|---|
| 外観 | 標準（デッキなし） | `LINE_ALBUM_コンテナパース_260714_7_0.jpg` |
| 外観 | ウッドデッキあり | `LINE_ALBUM_コンテナパース_260714_4_0.jpg` |
| 室内 | 標準 | `内装①.webp` |
| 室内 | エアコンあり | `室内パース/ベッドルーム.webp` |
| 水まわり | 洗面器あり | `洗面所.webp` |
| 平面図 | シャワー＋トイレ＋洗面＋エアコン | `平面図.jpg` |

一致しない組み合わせは「最も近い画像＋**画像に未反映：◯◯**」と表示され、管理画面 `/admin/preview-rules` に不足一覧として警告が出ます。
**BOX・フラットは画像が 1 枚もないため、外観・室内・平面図すべて「準備中」表示**です。

### 撮影・制作の共通仕様

- 同一ビュー内で**画角・カメラ位置・時間帯・背景を完全に揃える**（設備の有無だけが変わるように）
- 推奨サイズ：**2400×1650px（16:11）**、JPEG 品質 85 または WebP。平面図は白背景 PNG
- レイヤー方式（透過 PNG）なら、ベース 1 枚＋設備ごとの透過 PNG で全組み合わせを自動合成できる
