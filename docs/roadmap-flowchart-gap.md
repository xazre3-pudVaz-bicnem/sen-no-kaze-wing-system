## 4. 工程表

これは**開発工数の見積もり**です。着手順は、クライアントの営業・製造の実務が固まっている順に入れ替えます。

### ステップ0：案件の土台（最優先・約1.5週間）

ここを先にやらないと、フェーズ5以降がすべて作り直しになります。

| 項目 | 内容 |
| --- | --- |
| 案件（`projects`）の導入 | 見積単位ではなく**案件単位**でデータを束ねる。案件番号を本部システムで自動発行 |
| 番号体系の整理 | 案件番号／注文番号／個体番号の採番規則を確定し、共通の採番モジュールへ（既存の `quote_sequences` を一般化） |
| 進捗ステータス | 15フェーズを1本の遷移として定義し、監査ログ（`audit_logs`）と連動 |
| 代理店の担当者権限 | `organization_memberships` の member_role を実際の画面権限に接続 |

**要確認**：案件番号・注文番号・個体番号の**採番ルール（桁数・接頭辞・年度の扱い）**

### ステップ1：営業フローの完成（フェーズ2〜9／約2.5週間）

- **岩上さん**：商品マスター／見積テンプレート／管理画面（現在の延長）

`projects` は両者に関わるため、**着手前にテーブル設計だけ合意**してから分かれるのが確実です。
