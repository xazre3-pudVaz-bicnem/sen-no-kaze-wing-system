# 標準状態の商品の対応表（案）

- 作成日：2026-10-13
- 対象：初期登録する 10 件の標準見積（`docs/initial-registration.md`）
- 参照：確定資料の明細（初期登録の計画）と、商品台帳（2026-10-07 時点の本番カタログ）

## 決まり（2026-10-13 の先方回答）

- 対応付けるのは、商品台帳に登録済みで、メーカー・型番が確定している商品だけ
- メーカー・型番が未確定の商品は、既存の商品へ無理に紐付けず「商品確定待ち」で残す
- 商品が確定したら、商品台帳へ登録し、標準見積の次の Revision で正式な原価と標準状態の商品を設定する
- 標準状態の商品を登録しても、サイトの価格は切り替えない（切り替えのスイッチは本部が先方の最終確認のあとに入れる）

## 標準状態の商品とは

シミュレーターで、お客様が商品を変えたときの差額の基準です。

- 区分の金額 = 標準見積の明細小計 ＋（選んだ商品の価格 − 標準状態の商品の価格）
- 標準見積に含まれている商品・工事は、標準状態の商品として登録します。登録しないと、お客様がその商品を選んだときに、標準見積の金額に商品の価格が重ねて足されます（二重計上）
- 標準見積に含まれていない商品（商品確定待ちの設備機器は価格未確定で合計に入らない）は登録しません。お客様が選ぶと、商品台帳の価格が足されます

- **要確認**：Wing・Flat の標準見積には「室内造作」の明細がありません。商品台帳の「室内造作工事（住宅・ホテル仕様）312,500 円」「室内造作工事（事務所仕様）187,500 円」「室内造作工事（Flat）187,500 円」が、新しい標準見積のどの明細に含まれるか（含まれないか）を確認したい。含まれるなら対応付け、含まれないなら対応付けません（その場合、お客様が選ぶと台帳の価格が足されます）

## 3. 0 円の標準仕様

外壁 SP-ガルノート、サッシ 標準、内部建具 標準、床材（各色）、壁・天井 クロス仕上げ、照明器具 ダウンライト一式は、台帳の価格が 0 円です。対応付けてもしなくても金額は変わりません。差額の基準を画面で分かりやすくするため、標準の選択と同じものを対応付けます（案）。

## 進め方

1. 本番で初期登録（10 件の標準見積を第 1 版として公開。標準状態の商品は無し）
2. 標準見積ごとに次の Revision を作り、上の 1〜3 を標準状態の商品として登録して公開（サイトの価格は変わらない）
3. 本部のプレビュー（標準見積の一覧の「シミュレーターの価格」）で、機種・仕様ごとの金額を確認
4. 商品が確定したものから、商品台帳へ登録 → 次の Revision で原価と標準状態の商品を設定
5. 先方の最終確認のあと、サイトの新価格へ切り替え
