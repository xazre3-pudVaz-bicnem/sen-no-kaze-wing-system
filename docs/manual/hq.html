はじめに

管理画面は /admin です。会員登録したメールアドレスとパスワードで /login からログインすると、権限に応じたメニューが出ます。

4つの権限

権限は上位ほど広い操作ができます。付与は「ユーザー・権限」から行います。
権限できること主な担当
管理者 すべて。ユーザーの権限付与、代理店の割り当て、変更履歴の確認 技術の杜
総代理店 商品台帳への商品登録と価格の編集。本体・カテゴリー・商品・画像・プレビュー 総代理店
代理店・工務店 商品台帳の閲覧、自社フリー商品の登録、担当見積の別途工事入力 地域の代理店
顧客 見積シミュレーション・保存・見積依頼・見積への回答。管理画面には入れません エンドユーザー
Note

権限の判定はサーバー側とデータベース側の二重で行っています。メニューを隠しているだけではないので、URL を直接開いても操作はできません。

受注までの流れ

お客様の見積依頼から確定見積までの標準的な流れです。各段階で関係者に自動でお知らせが届きます。

お客様 シミュレーターで仕様を組み、見積を依頼する
本部 お知らせで受け取り、見積を開いて担当代理店を割り当てる
代理店 現地を確認し、別途工事とフリー商品を入力して確定見積（第2版）を発行する
お客様 確定見積を見て「この見積で進める」または「今回は見送る」を選ぶ
本部 回答のお知らせを受け取り、以降の手続きへ進む

見積の「版」について

お客様が依頼した時点の見積が第1版（概算見積）です。ここには工場生産分（本体・オプション）だけが入り、別途工事は「別途」と表示されます。代理店が金額を入れると第2版（確定見積）が新しく作られ、第1版は「改訂済み」として金額そのまま残ります。

見積番号は Q202608-0001 → Q202608-0001-2 と枝番が付きます。

Caution

発行済みの見積は金額を書き換えられません。マスターの価格を変えても、過去に発行した見積書の金額は変わらない設計です。金額を直したいときは、必ず新しい版を発行してください。

お知らせ

/admin/notifications　見積依頼・お問い合わせ・お客様の回答がここに届きます。まずこの画面を見れば、対応すべきことが分かります。

届くタイミング宛先
お客様が見積を依頼した本部
本部が代理店を割り当てたその代理店
代理店が確定見積を発行したお客様
お客様が承諾・辞退した本部と担当代理店
お問い合わせフォームが送信された本部
  1. 未読を確認する未読には赤いラベルが付きます。件名の右の「開く」で対象の画面へ移動します。
  2. 対応が終わったら既読にする右上の「すべて既読にする」でまとめて消せます。
メール通知について

環境変数 RESEND_API_KEY と MAIL_FROM を設定すると、同じ内容がメールでも届きます。未設定でもこの画面には必ず残るので、運用は止まりません。各お知らせに「メール送信済み／未送信」の状態が表示されます。

見積依頼・見積書

/admin/quotes　受け付けた見積依頼の一覧です。担当代理店の割り当てと、見積書 PDF の確認をここで行います。

担当代理店を割り当てる

  1. 一覧から見積を開く「担当代理店」の列が「未割当」のものが対象です。
  2. 右側の「担当代理店」から選ぶ代理店・総代理店の権限を持つ方だけが候補に出ます。候補にいない場合は先に「ユーザー・権限」で権限を付与してください。
  3. 「割り当てる」を押すその代理店にお知らせが届き、別途工事を入力できるようになります。

見積書 PDF

  • 「見積書PDF」で表示・ダウンロードできます。お客様のマイページからも同じものが取得できます。
  • レイアウトを変更したあとは「PDF再生成」で作り直せます。金額は変わりません。

見積書の構成

先方指定の区分です。1・2 は工場生産分、3・4・5 は現地の代理店が確定させます。
区分内容諸費用15%
1 本体価格躯体・金物・断熱・屋根外壁・サッシ建具かかる
2 オプション価格選ばれた設備・仕上げ（2-1 に明細）かかる
3 別途工事設計監理・梱包養生・現場設置・電気・給排水・基礎・廃材処分・現場諸費用かからない
4 運送費設置場所までの運搬かからない
5 フリー商品代理店・工務店の取扱商品（家具など）かからない

合計は 小計 → 値引き等調整額（千円未満切捨て）→ 税抜請負額 → 消費税10% → 合計 の順に、必ずサーバー側で計算します。

ステータス

発行済み 承諾 辞退 改訂済み 期限切れ 取消

「承諾」「辞退」はお客様の回答で自動的に付きます。「改訂済み」は代理店が次の版を発行したときに付きます。手動で変えたいときは詳細画面の「ステータス変更」を使います。

商品台帳

/admin/ledger　登録されているすべての商品を、階層で一覧できます。代理店も閲覧できます。

第1階層本体　Wing（片ウィング）／BOX／フラット
第2階層仕様　ホテル仕様／住宅仕様／事務所・店舗用
第3階層分類フォルダ　内外装仕上げ／サッシ／内部建具／設備機器／照明器具／家具／その他／防火仕様／別途工事／フリー商品
第4階層カテゴリー　床材・壁天井・浴室・トイレ など
第5階層商品　個々の製品と価格

各カテゴリーには「本体のみから」「本体＋設備から」「フル装備のみ」という注文範囲が付いています。これはお客様がどこまで頼むかを選んだときに、その項目が出るかどうかを決めるものです。

分類フォルダは増やせます

「オプションカテゴリー」から分類フォルダ名・分類コード・表示順を入力できます。コードを書き換える作業は不要です。

価格・商品の登録

総代理店以上の操作です。/admin/models（ベースコンテナ）、/admin/categories（オプションカテゴリー）、/admin/options（オプション）で編集します。

商品の価格を変える

  1. 「オプション」からカテゴリーを探し、商品の「編集」を押す
  2. 「価格（税別・円）」を書き換えて保存する諸費用15%と消費税は自動で計算されるので、税別の本体価格だけを入れてください。
  3. 反映を確認するシミュレーターの新しい計算にはすぐ反映されます。発行済みの見積書は変わりません。

新しいカテゴリーを追加する

  1. 「オプションカテゴリー」→ 新規作成
  2. 分類フォルダ名・分類コード・表示順を入れる既存のフォルダに入れるときは、同じ分類コードを指定します。
  3. 注文範囲を選ぶ本体のみ／本体＋設備から／フル装備のみ。内装や造作はフル装備のみが適切です。
  4. 選択方式を決める「1つ選択」はラジオ、「複数選択」はチェックボックスになります。
Caution

価格の変更は「変更履歴」に自動で記録されます。誰がいつどの商品をいくらに変えたかが残るので、複数人で運用しても追跡できます。

プレビュー画像

/admin/preview-rules　お客様が設備を選んだときに切り替わる完成イメージを管理します。

画像が見つからないときの動き

  1. 完全一致する画像を探す選ばれた設備の組み合わせにぴったりの画像があれば、それを表示します。
  2. レイヤー合成を試す透過 PNG が揃っていれば重ねて合成します。
  3. 最も近い画像を出す「画像に未反映：◯◯」と注記を付けて表示し、管理画面に不足として警告します。
絶対にしないこと

存在しない完成画像を作ったり、別仕様の写真を正しい完成図として出すことはしません。お客様に誤解を与えるためです。画像が足りない組み合わせは、必ず「未反映」と表示されます。

ダッシュボードに「プレビュー画像が不足している組み合わせ」の件数が出ます。素材が届いたら、この画面から登録してください。不足している画像の一覧は docs/required-preview-assets.md にまとめてあります。

ユーザー・権限

/admin/customers　登録ユーザーの一覧と、権限の付与を行います。管理者のみ。

  1. 対象の方に会員登録してもらうまず /register から通常のお客様として登録していただきます。
  2. 一覧からその方の行を探すメールアドレスで見つけられます。
  3. 権限を選んで「変更」を押す代理店・工務店／総代理店／管理者から選びます。
  4. 再ログインしてもらう次回ログイン時から管理画面に入れるようになります。
Caution

自分自身の権限は変更できません（管理者が誤って自分を降格し、誰も入れなくなるのを防ぐためです）。管理者を減らすときは、別の管理者から操作してください。

保存された仕様

/admin/configurations　お客様がマイページに保存した仕様の一覧です。まだ見積依頼に至っていないものも含まれます。

  • どのモデル・どの注文範囲で検討しているかが分かります。
  • 金額はマスターの現在価格で再計算した概算です。見積依頼が出ると、その時点の金額で見積書に固定されます。
  • 追客の材料として使えます。保存だけで止まっている方には、お問い合わせ経由でご連絡ください。

お問い合わせ

/admin/contacts　サイトのお問い合わせフォームから届いた内容です。

  • 添付ファイルは非公開の保管領域に入ります。この画面からのみ開けます。
  • 対応状況を「新規／確認中／対応済み」に変更できます。
  • 新着があるとダッシュボードとお知らせに出ます。

変更履歴

/admin/audit　価格・公開状態・権限が変更された記録です。管理者のみ閲覧できます。

種別記録される内容
価格変更商品・本体の価格を変えたとき（変更前後の金額つき）
公開状態商品・本体を公開／非公開にしたとき
権限変更ユーザーの権限を変えたとき
追加商品を新しく登録したとき

記録はデータベース側で自動的に作られます。画面を経由しない変更でも残ります。

運用上の約束

システムの設計としてこう決めている、という点です。運用のときに前提としてください。

  • 発行済みの見積は金額を変えない。マスターの価格を変えても過去の見積書は当時の金額のままです。修正は新しい版を発行して行います。
  • 価格・権限・見積番号はクライアント側では決めない。すべてサーバー側で再計算・採番します。
  • 存在しない完成画像は作らない。足りない組み合わせは「未反映」と明示します。
  • お客様は自分のデータしか見られない。他人の保存仕様や見積は開けません。代理店も割り当てられた見積だけです。
  • マイページと管理画面は検索エンジンに載せない。noindex を設定しています。

困ったときは

代理店が候補に出てこない

その方の権限がまだ「顧客」のままです。「ユーザー・権限」で代理店・工務店に変更してください。会員登録が済んでいない場合は、先に登録していただく必要があります。

価格を変えたのに見積書の金額が変わらない

正しい動作です。発行済みの見積はその時点のスナップショットです。新しい金額で出すには、代理店に確定見積（次の版）を発行してもらうか、お客様に見積を取り直していただきます。

お知らせは出るがメールが届かない

メール送信が未設定です。お知らせ画面の各行に「メール未送信」と表示されます。RESEND_API_KEY と MAIL_FROM を設定すると届くようになります。

お客様が「画像が未反映と出る」と言っている

その設備の組み合わせに対応する完成画像がまだ登録されていません。最も近い画像を出したうえで、正直に「未反映」と表示しています。プレビュー画像を登録すると解消します。

商品を削除できない

お客様が保存した仕様で使われている商品は削除できません。データが壊れるためです。代わりに非公開にしてください。新規の見積には出なくなります。
