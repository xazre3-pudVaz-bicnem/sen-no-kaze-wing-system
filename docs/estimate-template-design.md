# 標準見積テンプレート設計

## 目的

実物の分類表見積Excelを、そのまま標準見積の価格基準として保持する。
標準見積を `preset + options.price` から再構成しない。

## 価格の正本

標準見積の価格源は **Excelから取り込んだ標準見積テンプレートだけ** とする。

商品マスターの価格は、将来お客様が標準見積から商品を変更したときの差額・置換判定に使う。
標準状態の金額を商品価格から再計算してはいけない。

## 4分類

標準見積は次の4分類を固定で持つ。

1. `base` = 本体
2. `interior_exterior` = 内外装工事
3. `option` = オプション
4. `sitework` = 別途

## 保存先

- `base_breakdown_items`
  - 本体明細だけを保持する既存の正本。
  - 標準見積テンプレート側へ本体明細を複製しない。
- `estimate_templates`
  - Excel原本、仕様コード、税・調整額・最終合計など標準見積のヘッダー。
- `estimate_template_sections`
  - 4分類それぞれの明細小計、経費、分類合計。
- `estimate_template_lines`
  - 内外装工事・オプション・別途の明細。
  - `base` はDB制約で登録不可。

このため、標準見積全体は
`estimate_templates + estimate_template_sections + base_breakdown_items + estimate_template_lines`
で構成する。

## Excel取込時の検算

Excelに記録されている金額を正本とし、0.1円等の小数も切り捨てず保持する。
15%等の率は説明・異常検知用で、システム側の再計算値でExcel記載額を上書きしない。

登録前に必ず次を検算する。

- 各分類: 明細合計 + 経費 = 分類合計
- 4分類合計 = 小計
- 小計 + 値引き等調整額 = 税抜請負額
- 税抜請負額 × 消費税率（切捨て） = 消費税
- 税抜請負額 + 消費税 = 合計

税計算などで1円未満の差が生じる場合はExcel記載値を採用し、1円以上の不整合だけを異常として止める。

## 第1段階の対象

`20260901修正分類表見積書(3).xlsx` の実物シートを標準見積として扱う。

Wing:
- ウィング【本体】 -> `base`
- ウィング【ホテルUB】 -> `hotel`
- ウィング【単身者用】 -> `residence`
- ウィング【事務所】 -> `office`

BOX:
- BOX（本体） -> `base`
- BOX（ホテル単身者） -> `hotel-single`
- BOX（水回りキット） -> `water-kit`

BOXは旧 `hotel / residence / office` preset を標準見積の正本にしない。
管理画面では実物Excelに合わせて「本体のみ / ホテル・単身者用 / 水回りキット」を表示する。
水回りキット専用平面図も管理画面から登録できるが、シミュレーターへの切替接続は次段階とする。

Flat:
- フラット (本体) -> `base`
- フラット (物置事務所) -> `office`

Flatの実物Excelでは内外装ブロックの合計見出しも2つ目の `【本体価格計】` になっているが、
システム取込時はWingと同じ `interior_exterior = 内外装工事` として正規化する。
同ブロックの `本体諸費用` 表記も `内外装工事経費` として扱い、金額・数量・単価はExcel記載値をそのまま保持する。

防火シートは今回取り込まない。

## 標準見積と案件見積

標準見積テンプレートはExcel原本として固定し、取込後の本体明細も含めて直接編集しない。
変更は「Excel修正 → 再取込 → 全体検算 → 一括更新」で行う。

案件見積は標準見積をコピーして作成し、コピー後は標準見積と切り離す。
案件見積の権限は次のように分ける。
- 代理店: 自分に割り当てられた案件。本体は閲覧のみ。内外装工事・オプション・別途工事等を編集可能。
- 総代理店・本部: 本体を含めて案件見積の全項目を編集可能。
編集時は元の版を上書きせず、次版として発行して履歴を残す。

## シミュレーター接続

この段階では4ボタンへ接続しない。

次段階でシミュレーターを接続するときは、標準見積テンプレートをベースラインとし、
商品変更は明示的な「置換」または「差額」として反映する。
標準見積を `preset + options.price` から再構成する方式には戻さない。
