## 商品台帳（2026-08-22 の LINE フィードバックで確定した階層）

```
本体（base_models）
 ├ ①Wing ②BOX ③フラット
 └ ④その他 → 分類「防火仕様」：非防火仕様（基本仕様）／防火仕様（防火構造）
     └ 仕様（base_models.presets）：ホテル仕様／住宅仕様／事務所・店舗用
         └ 分類フォルダ（option_categories.group_code / group_name / group_sort）
             └ カテゴリー（option_categories）
                 └ 商品（options）
```

分類フォルダは 9 つ。**管理画面のカテゴリー編集から名称・コード・表示順を入力でき、増やせます**（コード直書きなし）。

| 分類フォルダ | カテゴリー |
|---|---|
| 内外装仕上げ | 床材・壁／天井・外壁 |
| サッシ | サッシ |
| 内部建具 | 内部建具 |
| 設備機器 | 浴室（ユニットバス）・トイレ・洗面・キッチン・給湯・空調 |
| 照明器具 | 照明器具 |
| 家具 | 家具・家電 |
| その他 | スマートロック・鍵／造作工事／外構部品／事務所用品 |
| 防火仕様 | 防火仕様 |
| 別途工事 | 別途工事（現地施工） |

- **④その他＝防火／非防火**は本体モデルではなく分類「防火仕様」として実装（Wing・BOX・フラットのどれでも選べる必要があるため）。防火仕様は「建築する場所によって異なる」ため **要見積（別途見積）** 扱いとし、`/dealers` へ誘導します。
- 商品がどの仕様で選べるかは `options.spec_codes`（空＝全仕様共通）で制御。例：折り畳み式ベッドはホテル・住宅のみ、事務所用品一式は事務所のみ。
- 別途工事（現地施工）：運送費・設計監理及び確認申請費・梱包養生・現場設置工事・電気設備工事・給排水給湯設備工事・基礎工事・廃材処分費・別途現場諸費用

## 注文範囲（2026-08-22 の先方フィードバック）

先方の定義：**本体＝木造躯体に屋根・外壁・サッシ・玄関ドアまでを工場で取り付けた状態**。
お客様はどこまで頼むかを選べる。画面（シミュレーター冒頭のカード）と商品詳細ページに説明を入れている。

| 注文範囲 | 含まれるカテゴリー（`option_categories.finish_level`） |
|---|---|
| 本体のみ（shell・DIY） | 外壁・サッシ・断熱仕様・防火仕様・別途工事 |
| 本体＋設備（equipment） | 上記＋浴室・トイレ・洗面・キッチン・給湯・空調・照明・家具・家電・スマートロック・外構部品・事務所用品 |
| フル装備（full） | 上記＋床材・壁／天井・内部建具・造作工事 |

- 必須カテゴリーの検証は**注文範囲に入っているカテゴリーだけ**に効く。本体のみで内装を要求しない。
- 範囲を狭めると範囲外の選択は自動で外れ、広げると仕様の標準構成から不足分を補う。
- 範囲は `configurations.finish_level` に保存し、発行時に `quotes.finish_level` へスナップショットする（画面・マイページ・管理画面・PDF に表示）。
- 各カテゴリーの範囲は管理画面のカテゴリー編集から変更できる（コード直書きなし）。
- 高断熱仕様（スタイロフォーム90mm）はあとから変更できないため、「スマートロック・鍵」から新設の**断熱仕様**カテゴリーへ移し、本体のみでも選べるようにした。

### 御見積書の構成（先方指定）

1. 本体価格 1式 → 2. オプション価格 1式（＋2-1 明細）→ 3. 別途工事 1式 → 4. 運送費 1式 → 合計
注記：「運搬、設置費など設置場所によって変動する費用は別途工事となっていて、現地の代理店、工務店にお問合せ下さい。」
→ 注記直下のリンクから **代理店紹介ページ `/dealers`**（別途工事の内訳・拠点一覧・問い合わせフォーム）へ。

### 煌・灯・翠の定義（修正）
